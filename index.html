1 · Connect GitHub

Use the owner/repository format. The account must own or have admin access to the repository.
Used in memory only to save code, create the encrypted bot-token secret, and start the workflow. Never put this token in your bot code. Use a fine-grained token scoped only to this repo, with Contents: Read and write, Actions: Read and write, and Secrets: Read and write.
The site sends this directly to GitHub's encrypted Actions Secrets API. It is not saved in the website or committed to source code.
Connect your repository to begin.
Security note: GitHub tokens are powerful. Create a narrowly scoped token, never share it, and revoke it from GitHub settings when finished. This browser page cannot hide secrets from browser extensions or a compromised device. Workflow runs are temporary (up to 6 hours); GitHub Actions is not a permanent 24/7 hosting service.
